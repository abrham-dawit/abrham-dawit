## About me

I'm a Computer Engineering senior at UC Santa Cruz (GPA 3.86, graduating June 2028) and a Software Engineer at the **Tech4Good Lab**, where I build a React/Node.js platform used by 50+ people across campus organizations. Before that I led production technology at UCSC's Performing Arts Technology Studio (embedded systems, live-event tech) and interned at Laney College's STEM Robotics Lab, building an autonomous color-sorting robot that hit ~95% accuracy.

I like high-stakes software: backend systems, infrastructure, and AI agents — places where correctness and reliability actually matter.

## Featured projects

**AgentCheck** — A multi-agent fact-checking pipeline in Python/FastAPI. Seven specialized agents split the work of researching claims, checking sources, and scoring confidence, so a claim gets verified from several angles instead of one pass.

**PolicyPulse** — A Next.js/TypeScript app that turns long policy documents into plain summaries people will actually read, with the source text kept one click away.


**Newton** — An FPGA project in Verilog on a Xilinx BASYS3 board: digital logic designed, simulated, and run on real hardware.

### Foundations — built from scratch

**[Data Structures & Algorithms in C/C++](https://github.com/abrham-dawit/data-structures-c-cpp)** — List and graph ADTs, BFS and strongly connected components, sparse matrices, arbitrary-precision integers, and BST + red-black tree dictionaries. Every structure implemented node by node, with my own test drivers.
